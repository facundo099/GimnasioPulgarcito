# 🏋️ GimnasioPulgarcito

Base de datos relacional desarrollada en **SQL Server** para la gestión integral de un gimnasio.

## 📋 Descripción

El sistema permite administrar clientes, empleados, profesores, clases, horarios y membresías de un gimnasio, asegurando la integridad de los datos mediante constraints, triggers y procedimientos almacenados.

## 🗂️ Estructura

- **Personas, Clientes y Empleados** — gestión de personas con roles diferenciados
- **Clases y Horarios** — organización de clases grupales con asignación de profesores
- **Membresías** — distintos planes con acceso a clases y/o piscina
- **Triggers** — validaciones automáticas sobre inserciones críticas
- **Stored Procedures** — alta de personas, clientes y empleados con validaciones
- **Vistas** — consultas predefinidas para reportes frecuentes

## ⚙️ Tecnologías

- SQL Server
- T-SQL
